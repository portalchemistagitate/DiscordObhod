>
> Добавьте каталог с zapret в исключения антивируса или отключите проверку PUA (потенциально нежелательных приложений). Если вы уверенно понимаете настройки исключений, предпочтительнее добавить исключение. При сомнениях рекомендуется отключить детектирование PUA.

## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS).
    * В Chrome активируйте пункт "Использовать безопасный DNS" и выберите конкретного поставщика, не оставляя вариант "Поставщик по умолчанию".
    * В Firefox откройте настройку "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
    * Windows 11 позволяет включить Secure DNS непосредственно в настройках системы — [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 этот способ рекомендуется.
    * Владельцам роутеров Keenetic нужно активировать в настройках опцию "Транзит запросов". Если её отключить, Secure DNS на компьютере может работать некорректно.

2. Скачайте zip- или rar-архив с [последнего релиза](https://github.com/portalchemistagitate/zapret-discord-youtube/releases/latest).

3. Откройте свойства загруженного архива и включите флажок "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот пункт можно не выполнять.

4. Распакуйте архив в каталог, путь к которому не содержит кириллицу и специальные символы.

5. Запустите подходящий файл.
    * Для поиска работающей стратегии откройте **`service.bat`** и выберите `Run Tests` -> `Standard tests` -> `All configs`.
    * Чтобы включить запуск вместе с системой, используйте **`service.bat`** -> `Install Service` -> *выберите нужную стратегию*.

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии.

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую именно для вас**.

- [**`service.bat`**](./service.bat) — установка автозапуска и дополнительные операции:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск через services.msc.</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из списка служб.
  - **`Check Status`** — посмотреть состояние обхода и служб, включая стратегию в автозапуске и WinDivert.
  - **`Game Filter`** — изменить режим обхода для игр и других сервисов, работающих с UDP и TCP на портах выше 1023.  
  **После изменения режима стратегию необходимо перезапустить.**  
  Текущее состояние (включено или выключено) отображается в скобках.
  - **`IPSet Filter`** — выбрать режим обхода сервисов, перечисленных в `ipset-all.txt`.  
  Опция пригодится при проверке ресурса, который без zapret доступен, а с ним перестаёт работать.  
  В скобках показывается текущее состояние:
    - `none` — ни один IP не проходит проверку
    - `loaded` — проверяются IP из списка
    - `any` — под фильтр попадает любой IP  
  - **`Auto-Update Check`** — включить или выключить автоматический поиск обновлений.
  - **`Replace active fakes`** — заменить выбранный используемый fake на другой файл из каталога `bin`.
  - **`Update IPSet List`** — загрузить актуальный `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** — обновить hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовым чатам Discord**</ins>.
  - **`Check for Updates`** — вручную проверить наличие обновлений.
  - **`Run Diagnostics`** — выполнить диагностику распространённых причин неисправности zapret.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает после внезапной остановки работы клиента.
  - **`Run Tests`** — открыть средство проверки стратегий:
    - `Standard tests` — протестировать сайты из `utils/targets.txt`.
    - `DPI checkers` — проверить DPI у разных провайдеров, включая Cloudflare и Amazon.


## ☑️Распространенные вопросы и проблемы

### После запуска скрипта `general*` ничего не происходит

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe (обход), видимый на панели задач.  
Если процесс не запускается, обратитесь к [#522](https://github.com/portalchemistagitate/zapret-discord-youtube/issues/522).

### Ни одна стратегия не подходит
- Откройте командную строку с правами администратора.
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер.

### Не работает телеграм (веб версия)
Откройте **`service.bat`** и запустите **`Update hosts file`**. Если файл hosts окажется устаревшим, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открывшегося блокнота.
  - В появившейся папке откройте файл `hosts` через текстовый редактор, запущенный от имени администратора.
  - Вставьте скопированные данные в конец `hosts` или замените ими ранее добавленный аналогичный блок.
  - Сохраните файл и проверьте подключение ещё раз. При отсутствии результата убедитесь, что изменения действительно сохранились.

#### Работа не гарантирована. Если это не помогло, используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/portalchemistagitate/tg-ws-proxy) либо с любым публичным прокси.

### Обход не работает / перестал работать

> [!IMPORTANT]
> **Работоспособность стратегий со временем может исчезать.**
> Стратегия иногда функционирует в течение некоторого периода, а затем перестаёт работать после её обнаружения.
> Здесь доступно много вариантов обхода. Если готовые решения не подходят, создайте новую стратегию на основе одной из имеющихся и измените её параметры.
> Описание параметров можно найти [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Запустите `service.bat` -> `Run Diagnostics` и убедитесь, что там нет ошибок.

- Проверьте, присутствует ли адрес нужного ресурса в доменных или IP-списках.

- Попробуйте другие варианты, включая **`ALT`**, **`FAKE`** и прочие стратегии.

- Выполните полную переустановку по инструкции ниже.

- Дополнительная информация находится в [#765](https://github.com/portalchemistagitate/zapret-discord-youtube/issues/765).

### Как переустановить/обновить полностью?
- Сохраните ресурсы и данные, которые добавляли самостоятельно.
- Перезапустите устройство.
- Откройте `service.bat` -> `Remove Services`.
- Выполните `service.bat` -> `Run Diagnostics`; если появятся ошибки, исправьте их, а в конце подтвердите действие клавишей Y.
- Удалите каталог с zapret.
- Загрузите свежую версию со [страницы релизов](https://github.com/portalchemistagitate/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`).
- Нажмите правой кнопкой мыши на архиве и выберите свойства. Если в нижней части окна есть флажок разблокировки, установите его, нажмите применить и затем ОК.
- Распакуйте архив в новую папку в корне диска; путь не должен содержать пробелы и специальные символы.
- По очереди запускайте разные скрипты `general` и проверяйте доступ к интернет-ресурсам. Если выбранная стратегия не работает, закройте программу через значок замка на панели задач и попробуйте следующую.
- После нахождения рабочей стратегии добавьте её в автозапуск через `service.bat` -> `Install Service` -> выберите нужный вариант.

### Не работает игра/приложение с включённым запретом

- В `service.bat` проверьте, что `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит ругается на WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Требуется цифровая подпись драйвера WinDivert (Windows 7)

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### При удалении с помощью [**`service.bat`**](./service.bat), WinDivert остается в службах

1. Найдите имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что [Secure DNS](#%EF%B8%8Fиспользование) настроен.
- Отключите блокировщик рекламы: известно, что YouTube начал противодействовать таким расширениям.
- Если прежняя стратегия больше не помогает, переберите остальные.
- См. также [#251](https://github.com/portalchemistagitate/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) включён.
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить именно её.
- В `service.bat` выберите `Run Diagnostics`, затем очистите кэш Discord.
- После очистки проверьте приложение Discord.
- Откройте Discord в браузере по адресу https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей.
- Если Discord не открывается и в браузере, снова проверьте все стратегии: YouTube и Discord могут работать на разных вариантах.
- См. также [#252](https://github.com/portalchemistagitate/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/portalchemistagitate/tg-ws-proxy).
- Также можно подключить бесплатный MTProto-прокси из интернета.

### Не работают игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Попробуйте универсальную последовательность:
- через `service.bat` обновите ipset и включите `Game Filter`;
- если результата нет, дополнительно активируйте `ipset any`.

Учтите, что режим `ipset any` может нарушить открытие многих сайтов. Не оставляйте его включённым постоянно: определите все IP-адреса, используемые игрой, и внесите их в `ipset-all.txt`.

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/portalchemistagitate/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли своей проблемы

- Оформите обращение [здесь](https://github.com/portalchemistagitate/zapret-discord-youtube/issues).

## 🗒️Добавление адресов прочих ресурсов

Дополнительные адреса для обхода добавляются в следующие файлы:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически.
- **`list-exclude-user.txt`** — домены-исключения, например когда IP сети есть в `ipset-all.txt`, но конкретный домен из этой сети фильтровать не нужно.
- **`ipset-all.txt`** — IP-адреса и подсети.
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые нужно исключить.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
